# AI Limit 0.3.24

## 中文

AI Limit 0.3.24 是首个公开发布的 Windows 托盘版本，新增 Claude Code 和 Codex 双额度图标、双语详情面板、可配置刷新间隔，以及带 Ed25519 签名验证的可见更新流程；macOS 菜单栏应用和命令行工具继续保留。

### Windows 下载

普通用户只需下载并运行：

- `ai-limit-0.3.24-setup.exe`

`.sig` 文件由应用内更新器自动获取，手动安装的用户无需下载或打开。维护者发布时必须同时上传：

- `ai-limit-0.3.24-setup.exe.sig`

安装包 SHA-256：

```text
E95AB223CEA5CA3397EE0E51E40FCE4AAAE64D0879A1CE62E091428AE7E54DBF
```

签名文件 SHA-256：

```text
5CEBF14EB3DCE93DAF461B2282EE8CAB7171E3ED62AA6EBCD3303B72F2EDE3E1
```

Ed25519 发布密钥标识：`a79b47e1424f9504`。

### 安装前说明

- 当前已验证的 Windows 目标为 Windows 11。
- 请先使用 Firefox 登录 Claude 和/或 ChatGPT。由于 App-Bound Encryption（应用绑定加密），Windows 应用无法读取 Chrome 或 Edge 的 Cookie。
- 本版本尚未进行 Authenticode 代码签名，Windows 可能显示“未知发布者”或 Microsoft Defender SmartScreen 警告。

### 主要变化

- 两个紧凑托盘图标分别显示 Claude Code 和 Codex 额度。
- 点击任一图标可以打开或关闭共享详情面板。
- 面板显示 5 小时和 7 天额度、重置时间、套餐及服务状态。
- 中英文界面可直接切换。
- 自动刷新间隔可设为 1–5 分钟，修改后底部状态立即更新。
- 安装器支持简体中文和英文，可按当前用户安装并设置开机启动。
- 更新器会在启动安装包前拒绝缺失签名、内容篡改、签名错误和版本不符的文件。

## English

AI Limit 0.3.24 is the first public Windows tray release. It adds compact Claude Code and Codex quota icons, a bilingual detail panel, configurable refresh intervals, and a visible update flow protected by Ed25519 release-signature verification, while retaining the existing macOS menu bar app and command-line interface.

### Windows download

Ordinary users only need to download and open:

- `ai-limit-0.3.24-setup.exe`

The `.sig` file is fetched automatically by the in-app updater; manual-install users do not need to download or open it. Release maintainers must also upload:

- `ai-limit-0.3.24-setup.exe.sig`

Installer SHA-256:

```text
E95AB223CEA5CA3397EE0E51E40FCE4AAAE64D0879A1CE62E091428AE7E54DBF
```

Signature-file SHA-256:

```text
5CEBF14EB3DCE93DAF461B2282EE8CAB7171E3ED62AA6EBCD3303B72F2EDE3E1
```

Ed25519 release-key identifier: `a79b47e1424f9504`.

### Before installing

- Windows 11 is the currently verified Windows target.
- Sign in to Claude and/or ChatGPT with Firefox. The Windows application cannot read Chrome or Edge cookies because of App-Bound Encryption.
- This release is not Authenticode code-signed. Windows may show an “Unknown publisher” or Microsoft Defender SmartScreen warning.

### Highlights

- Two compact tray icons show Claude Code and Codex quota independently.
- Clicking either icon toggles the shared detail panel.
- The panel shows 5-hour and 7-day quota, reset time, plan, and service state.
- Chinese and English interfaces can be switched directly.
- Automatic refresh can be set from 1 to 5 minutes and updates the footer immediately.
- The installer supports Simplified Chinese and English, installs per user, and can start AI Limit with Windows.
- Updates reject missing signatures, tampered installers, wrong signatures, and wrong versions before launch.
