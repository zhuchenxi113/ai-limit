# AI Limit 0.3.24

AI Limit 0.3.24 is the first public Windows tray release. It adds compact Claude Code and Codex quota icons, a bilingual detail panel, configurable refresh intervals, and a visible verified update flow while retaining the existing macOS menu bar app and command-line interface.

## Windows download

Ordinary users only need to download and open:

- `ai-limit-0.3.24-setup.exe`

Release maintainers must also upload this sidecar asset beside the installer:

- `ai-limit-0.3.24-setup.exe.sig`

## Before installing

- Windows 11 is the currently verified Windows target.
- Sign in to Claude and/or ChatGPT with Firefox. The Windows application cannot read Chrome or Edge cookies because of their App-Bound Encryption.
- This release is not Authenticode code-signed. Windows may show “Unknown publisher” or a Microsoft Defender SmartScreen warning.
- The `.sig` file is fetched automatically by the in-app updater. Users installing the downloaded `.exe` manually do not need to download or open the `.sig` file.

See the [Windows update security design](../windows-update-security.md) for the distinction between the Ed25519 release signature and Windows Authenticode publisher identity.

## Highlights

- Two compact tray icons show Claude Code and Codex quota independently.
- Clicking an icon toggles the shared panel open and closed.
- The panel shows 5-hour and 7-day quota, reset time, plan, and service state.
- Chinese and English interfaces include a bilingual language switcher.
- Automatic refresh can be set from 1 to 5 minutes and updates the footer immediately.
- The installer supports English and Simplified Chinese, installs per user, and can start AI Limit with Windows.
- Updates reject missing signatures, tampered installers, wrong signatures, and wrong versions before launch.
