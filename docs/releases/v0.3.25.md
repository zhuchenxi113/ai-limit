# AI Limit 0.3.25

AI Limit 0.3.25 is a corrective cross-platform release. On Windows it fixes the final installer-launch step of in-app updates and adds a selectable installation directory with safe migration from the previously registered location. The macOS application uses the same version number so both platforms stay on one release line.

### Upgrading from Windows v0.3.24

The updater included in v0.3.24 can download and verify an update but may remain at “Updating…” before the installer opens. If this occurs, exit AI Limit, download `ai-limit-0.3.25-setup.exe`, and run it manually. This one-time manual installation places the corrected updater on the machine.

The setup wizard now allows a custom installation directory. If a different directory is selected during an upgrade, setup asks for confirmation, runs the previously registered uninstaller, verifies that the previous executable is gone, and then installs to the new directory.
