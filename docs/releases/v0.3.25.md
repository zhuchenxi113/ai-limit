# AI Limit 0.3.25

## 中文

AI Limit 0.3.25 是一次跨平台修正版本。Windows 端修复了应用内更新流程中"启动安装程序"这最后一步的问题，并新增可自定义、可从旧安装位置安全迁移的安装目录选择。macOS 应用采用相同版本号，两个平台保持同一条发布线。

### Windows 下载

普通用户只需下载并运行：

- `ai-limit-0.3.25-setup.exe`

维护者发布时必须同时上传这个配套文件：

- `ai-limit-0.3.25-setup.exe.sig`

`.sig` 文件由应用内更新器自动获取，手动安装的用户无需下载或打开。

安装包 SHA-256：

```text

```

签名文件 SHA-256：

```text

```

Ed25519 发布密钥标识：`a79b47e1424f9504`。

#### 从 Windows v0.3.24 升级

v0.3.24 自带的更新器可以下载并验证更新，但在打开安装程序前可能会一直停在"更新中…"。如果遇到这种情况，请退出 AI Limit，手动下载并运行 `ai-limit-0.3.25-setup.exe`。这次手动安装会把修复后的更新器装到本机，此后的自动更新将走修复后的启动路径。

安装向导现在允许自定义安装目录。如果升级时选择了与旧版不同的目录，安装程序会先确认，再运行旧版登记的卸载程序，确认旧版可执行文件已删除后，才安装到新目录。

## English

AI Limit 0.3.25 is a corrective cross-platform release. On Windows it fixes the final installer-launch step of in-app updates and adds a selectable installation directory with safe migration from the previously registered location. The macOS application uses the same version number so both platforms stay on one release line.

### Windows download

Ordinary users only need to download and open:

- `ai-limit-0.3.25-setup.exe`

Release maintainers must also upload this sidecar asset beside the installer:

- `ai-limit-0.3.25-setup.exe.sig`

The in-app updater fetches the `.sig` file automatically; users installing manually do not need to download or open it.

```text

```

Signature-file SHA-256:

```text

```

Ed25519 release-key identifier: `a79b47e1424f9504`.

#### Upgrading from Windows v0.3.24

The updater included in v0.3.24 can download and verify an update but may remain at "Updating…" before the installer opens. If this occurs, exit AI Limit, download `ai-limit-0.3.25-setup.exe`, and run it manually. This one-time manual installation places the corrected updater on the machine, and future automatic updates will use the corrected launch path.

The setup wizard now allows a custom installation directory. If a different directory is selected during an upgrade, setup asks for confirmation, runs the previously registered uninstaller, verifies that the previous executable is gone, and then installs to the new directory.
