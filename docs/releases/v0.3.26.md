# AI Limit 0.3.26

## 中文

AI Limit 0.3.26 改进了 Windows 托盘额度图标在深色/浅色任务栏上的清晰度与主题切换响应，并从本版本起为公开安装资产标明平台名称。

### Windows 下载

普通用户只需下载并运行：

- `ai-limit-windows-0.3.26-setup.exe`

应用内更新器会自动下载精确配对的 Ed25519 签名文件，手动安装的用户无需下载或打开 `.sig`。为兼容 v0.3.25 已发布更新器，本 Release 还包含旧文件名安装包及独立签名；它们仅供旧版自动更新使用，无需手动下载。


### Windows 托盘图标

- Windows 切换任务栏深色/浅色模式后，Claude 与 CodeX 图标会立即重绘，不再残留旧主题颜色。
- Explorer 重建通知区域后，两个图标会自动恢复；安装路径发生变化时若固定 GUID 注册被 Windows Shell 拒绝，会回退到窗口句柄与图标 ID 身份，避免进程仍在但图标消失。
- Claude 数字采用粗体浅白/橙色分区，CodeX 数字采用粗体黑/白分区；填充边界穿过数字时仍保持反差。
- README 的 Windows 托盘图标截图已更新为当前样式。

## English

AI Limit 0.3.26 improves the clarity and theme-switch response of the Windows quota tray icons and adds platform-qualified names to public installation assets.

### Windows download

Ordinary users only need to download and run:

- `ai-limit-windows-0.3.26-setup.exe`

The in-app updater automatically fetches the exact matching Ed25519 signature; manual installers do not need to download or open the `.sig` file. This Release also contains an independently signed legacy-name installer for compatibility with the updater shipped in v0.3.25. Those compatibility assets are for automatic updates only and do not need to be downloaded manually.

Official Windows installer SHA-256:

```text
22F076A9703E4DCFC24222E4807040A037E7A00D14257C7FC7DE5A26B45B2850
```

Official signature-file SHA-256:

```text
FBB58CEC1084A9E760087E0A868C962CDF027B04510830644802100E875351D5
```

The legacy-name installer has identical content and the same SHA-256, `22F076A9703E4DCFC24222E4807040A037E7A00D14257C7FC7DE5A26B45B2850`. Its independently bound signature file has SHA-256 `E2A261320C3D7C5664067FA802751BD5AA327C64188A873C765DACD540CE9D02`.

Ed25519 release-key identifier: `a79b47e1424f9504`.

### Windows tray icons

- Claude and Codex icons redraw immediately after Windows switches the taskbar between light and dark modes instead of retaining stale theme colors.
- Both icons recover after Explorer rebuilds the notification area. If Windows Shell rejects fixed-GUID registration after the executable path changes, the app falls back to window-handle and icon-ID identity instead of remaining alive without visible icons.
- Claude digits use a bold white/orange split, while Codex digits use a bold black/white split, preserving contrast when the fill boundary crosses a digit.
- The Windows tray-icon screenshot in the README now reflects the current design.
